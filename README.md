# 영상 자막 (video-subtitle)

삼성 비디오 플레이어 등에서 재생되는 영상 소리를 받아, 영어·일본어·중국어 대사를 **한국어 자막**으로 화면 위/아래에 띄우는 안드로이드 앱입니다. (Android 10 이상)

## 설치
1. 이 저장소의 **Releases**에서 최신 `video-subtitle.apk`를 폰으로 내려받습니다.
2. 설치 시 "출처를 알 수 없는 앱" 허용이 필요할 수 있습니다.

## 사용
1. 앱을 열고 Gemini API 키를 입력 → **자막 시작**
2. 마이크(오디오 녹음) · 알림 · 다른 앱 위에 표시 · 화면 공유 권한을 차례로 허용
3. 비디오 플레이어에서 영상 재생 → 자막 표시

동그란 **자막** 버튼: 탭 = 켜기/끄기, 길게 = 위/아래 전환, 끌기 = 이동
알림에서도 끄기 / 위치 / 종료 가능

## 구조
- `MainActivity` — 설정, 권한 요청
- `CaptionService` — 미디어 소리만 캡처(16kHz) → 말소리 단위로 자르기(0.7초 쉬면 끝, 최대 7초) → 번역 요청(동시 2건, 밀리면 최신 우선) → 자막 표시
- `GeminiClient` — Gemini API 호출 (앞 대사 3줄을 문맥으로 함께 보냄)
- 글꼴: Noto Sans KR 500 (빌드할 때 자동으로 받아 포함)

## 빌드
`main`에 올리면 GitHub Actions가 APK를 만들어 Releases에 올립니다.
